# Getting help

This page applies to every Solarity-AI repository that doesn't have its own `SUPPORT.md`.

## Where to ask

- **A question about using a tool:** open an issue with the **Question** form on that repository.
- **A bug:** open an issue with the **Bug report** form on that repository, with the steps to reproduce.
- **An idea:** open an issue with the **Feature or improvement** form.
- **A security problem:** don't open a public issue; follow the [security policy](SECURITY.md).
- **Anything else** (press, partnerships, the apps or the SaaS products): email
  [ata.turhan@solarityai.com](mailto:ata.turhan@solarityai.com) or visit [solarityai.com](https://solarityai.com/).

## What to expect

We read every issue and email, and reply as soon as we can. Issues are the fastest route for anything about the code.
